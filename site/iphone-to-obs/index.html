Put your iPhone in OBS on Windows (green-screen capture)

Streaming or recording a phone screen in OBS usually means fighting window borders, shadows and rounded corners. AirGlass Pro's OBS mode swaps all of that for a plain rectangle on solid chroma-key green, built for OBS's Window Capture.

Why mirroring windows don't key out cleanly

AirGlass's normal glass window has a refractive rim, a shadow and rounded corners that pick up whatever's behind them, so a straight Window Capture in OBS brings all of that along. OBS mode removes it: the window becomes a flat rectangle filled with solid green (#00B140) around the mirrored picture, with no glass, shadow or on-screen controls, so a Chroma Key filter has a clean background to remove.

Set it up

  1. Mirror your iPhone or iPad. Install AirGlass, open Control Center's Screen Mirroring on the device, and pick your PC.
  2. Switch to OBS mode. Press O, or use the tray icon or the window's right-click menu. The window is now titled AirGlass (OBS) and filled with solid green around the picture. AirGlass remembers the choice for next time.
  3. Add a Window Capture source in OBS. In OBS Studio, click + under Sources, choose Window Capture, and pick the window titled AirGlass (OBS).
  4. Key out the green. Right-click the source, open Filters, add a Chroma Key filter, and set the colour to green (#00B140 is the exact shade AirGlass uses). Adjust similarity until the edges look clean.

Don't want to key it out? Skip the Chroma Key filter and crop the Window Capture to the picture instead — you'll get a plain rectangular phone screen with a thin green border.

OBS mode is part of AirGlass Pro, $9.99 once.

While you're live

Everything else about the mirror keeps working in OBS mode: lossless AirPlay music still plays through the PC, and if the sender offers AirPlay remote control, Space and Ctrl+arrow keys play, pause and skip tracks without touching the phone. Drawing and region zoom are for the normal glass window; OBS mode is built to stay a plain, stable rectangle for the capture.

Questions

Can I show my iPhone screen in OBS?

Yes. Mirror the iPhone to Windows with AirGlass, switch the window to OBS mode, and add it to OBS as a Window Capture source.

Do I need a physical green screen?

No. OBS mode replaces the glass window itself with a plain rectangle on solid chroma-key green (#00B140), so OBS's own Chroma Key filter can remove the background without any physical screen.

Is OBS mode free?

No, OBS mode is part of AirGlass Pro, a $9.99 one-time upgrade usable on up to 3 PCs. The free edition mirrors full screen only.

Will OBS lose the window if I switch devices?

No. The capture window keeps the title "AirGlass (OBS)" so the same OBS source keeps finding it, and AirGlass remembers that you want OBS mode for next time.
