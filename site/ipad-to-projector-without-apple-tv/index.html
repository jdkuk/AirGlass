Show an iPad on the classroom projector, without an Apple TV

Most classrooms already have a Windows PC wired to the projector. Instead of buying an Apple TV for every room, install a small receiver on that PC and the iPad mirrors to it over AirPlay the same way.

Why an Apple TV isn't the only option

Apple TV is the usual way a classroom gets AirPlay, but it means another box, another remote and another thing on the AV budget for every room — on top of the PC that's probably already connected to the same projector or screen. AirGlass turns that existing PC into the AirPlay receiver instead: install it once, and iPads and iPhones see the PC in Screen Mirroring exactly as they would an Apple TV.

Set up a classroom PC

  1. Install AirGlass on the PC connected to the projector. Download the installer and run it; it starts with Windows and sits in the tray.
  2. Name it after the room. Right-click the tray icon → Rename this PC… so "Room 12" or "Science Lab" is what shows up in Screen Mirroring, not the PC's network name.
  3. Lock it down (Pro). Turn on Require a code to connect so a 4-digit code appears on the projector that a new iPad has to type once, or Ask before new devices connect to approve each one from the PC. Either stops a device outside your class from mirroring by mistake.
  4. Mirror from the iPad. Open Control Center, tap Screen Mirroring, and choose the room's name.

One setup, every room

For more than a handful of PCs, configuring the PIN or allow-list by hand on each one doesn't scale. AirGlass reads a machine-wide setting from %ProgramData%\AirGlass\airglass.ini that an IT department can roll out once: a fixed receiver name, and requirePin=1 or askNewDevices=1 under [security] to turn the code or the allow-list on for the whole fleet without touching every PC by hand. Full detail is in the deployment docs.

Mirroring is free. The PIN, allow-list and drawing are part of Pro, $9.99 once per PC.

During the lesson

With AirGlass Pro, pressing D brings up a pen, arrow, highlighter and eraser with an on-screen toolbar, so a teacher can annotate straight over whatever the iPad is showing — working through a diagram, circling a mistake, marking up a map — without leaving the mirrored view. Z drags out a region to zoom into, useful for a small detail the back row can't read.

Questions

Do we need an Apple TV to AirPlay an iPad to the classroom projector?

No. If a Windows PC is already wired to the projector, installing AirGlass on it turns that PC into an AirPlay receiver, so the iPad shows up in Screen Mirroring the same way it would for an Apple TV.

How do we stop other students' devices connecting?

AirGlass Pro adds two options: "Ask before new devices connect", which asks on the PC before an unrecognised device is allowed, and "Require a code to connect", which shows a 4-digit code on the projector that a device must type once before it can mirror.

Can IT set this up the same way on every classroom PC?

Yes. A setting under %ProgramData%\AirGlass\airglass.ini applies machine-wide: a fixed receiver name per room, and turning on the PIN code or the allow-list for everyone, without each PC being configured by hand.

Can a teacher draw on the screen during the lesson?

Yes, with AirGlass Pro. Pressing D brings up a pen, arrow, highlighter and eraser with an on-screen toolbar, so a teacher can annotate directly over the mirrored iPad screen.
